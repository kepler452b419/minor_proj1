ESP32 Temperature & Humidity Monitoring System

An IoT project developed using ESP32 and DHT22 sensor in Wokwi Simulator to monitor real-time temperature and humidity data and upload it to ThingSpeak cloud for live visualization and analysis.

Technologies Used
- ESP32
- DHT22 Sensor
- Wokwi Simulator
- ThingSpeak
- Arduino IDE

Features
- Real-time monitoring
- Cloud data logging
- Live graphs on ThingSpeak
- WiFi-enabled ESP32 communication

Simulation
Built and tested using Wokwi Simulator.

Applications
Smart home automation, weather monitoring, and environmental sensing.
